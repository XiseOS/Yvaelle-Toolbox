# Yvaelle's Toolbox

Downloads for a Foundry VTT 14 module. This branch holds the **release** channel's manifest.

- Release: `https://raw.githubusercontent.com/XiseOS/Yvaelle-Toolbox/release/module.json`
- Beta: `https://raw.githubusercontent.com/XiseOS/Yvaelle-Toolbox/beta/module.json`

In Foundry: Add-on Modules › Install Module › paste one of the addresses into *Manifest URL*. The zips are under Releases.
